## Install

You need **Python 3.11 or newer** — check with `python --version`.

<Tabs syncKey="installer">
<TabItem label="pip">

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate    # macOS / Linux

pip install buraq
```

</TabItem>
<TabItem label="uv">

```bash
uv venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate    # macOS / Linux

uv pip install buraq
```

No uv yet? `curl -LsSf https://astral.sh/uv/install.sh | sh` on macOS and Linux,
`powershell -c "irm https://astral.sh/uv/install.ps1 | iex"` on Windows. It
installs faster than pip; nothing here needs it.

</TabItem>
</Tabs>

That environment now holds Buraq, and it is where your project's packages go
too. Check it worked:

```bash
buraq --version
# Buraq 1.6.0
```

## Create a project

```bash
buraq startproject myproject
cd myproject
```

You get `config/` (settings and URLs), `main.py`, `manage.py`, a `pyproject.toml`
listing Buraq, and a `.env` holding a freshly generated `SECRET_KEY`.

That is all it does — no environment, no install. You are already in one, which
is how you ran the command.

## Run it

```bash
buraq migrate
buraq runserver
```

Your project is on `http://127.0.0.1:8000`, and the auto-generated API docs are
at `/api/docs`.

## Adding your own packages

Into the same environment as Buraq:

```bash
pip install httpx            # or: uv pip install httpx
```

Record them in the project's `pyproject.toml` so the next person gets them too.

## Database drivers

SQLite works out of the box — `aiosqlite` is bundled, nothing to install. For
anything else, add the driver **inside the project**:

<Tabs syncKey="installer">
<TabItem label="uv">

```bash
uv add "buraq[postgres]"         # PostgreSQL
uv add "buraq[mysql]"            # MySQL / MariaDB
```

</TabItem>
<TabItem label="pip">

```bash
pip install "buraq[postgres]"    # PostgreSQL
pip install "buraq[mysql]"       # MySQL / MariaDB
```

</TabItem>
</Tabs>

Then point `DATABASE_URL` at it in `config/settings.py` — see
[Settings](/docs/getting-started/settings).

## Troubleshooting

**`No pyproject.toml found in current directory or any parent directory`** —
from `uv add buraq`. `uv add` adds a dependency to a project that already
exists, and you do not have one yet. Use `uv pip install buraq` as above;
`uv add buraq` is for adding Buraq to a project you already have.

**A package you installed is not found, and you used `uv tool install buraq` or
`pipx`** — those put `buraq` on your PATH inside an environment of their own,
holding Buraq and nothing of yours. Convenient for trying Buraq out, not enough
to build with. Make an environment as above.

**`buraq: command not found`** — the environment is not activated. Activate it,
or use `python -m buraq` in place of `buraq`. If you installed with
`uv tool install`, run `uv tool update-shell` and open a new terminal.

**`ModuleNotFoundError` for a package you installed** — you are in a different
environment from the one you installed into. `buraq shell -c "import buraq;
print(buraq.__file__)"` prints where the running Buraq is being read from.

**You want the environment made for you** — `buraq startproject myproject
--install` creates a `.venv` in the project and installs into it, with `uv` when
it is there and `venv` + `pip` when it is not. Without the flag the project is
files only, and runs in whatever environment you are already using.

**The `--install` step failed** (no network, a blocked index) — the project files
are still correct. `buraq startproject` prints the one command left to run; run
it from inside the project.

**You want the project somewhere else** — name a directory second:
`buraq startproject myproject blog_folder`. Files land directly in it. `--dest`
does the same thing.
