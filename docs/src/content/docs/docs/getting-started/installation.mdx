## Requirements

- **Python 3.11+**
- An async database driver (pick one based on your database)

## Install the `buraq` command

Starting a new project needs the `buraq` command before any project exists, so
install it as a tool rather than as a dependency:

<Tabs>
<TabItem label="uv (recommended)">

```bash
uv tool install buraq
```

</TabItem>
<TabItem label="pip">

```bash
pip install buraq
```

</TabItem>
</Tabs>

:::caution
`uv add buraq` does not work at this point. `uv add` adds a dependency to a
project that already has a `pyproject.toml`, and you do not have one yet — it
fails with `No pyproject.toml found in current directory or any parent
directory`. Use `uv add buraq` only to add Buraq to an existing project.
:::

Check it is available:

```bash
buraq --version
```

## Create your project

This is the step that creates files:

```bash
buraq startproject myproject
cd myproject
uv sync
```

`startproject` writes `config/`, `alembic/`, `main.py`, `manage.py`, a
`pyproject.toml` that already lists Buraq, and a `.env` holding a freshly
generated `SECRET_KEY`. `uv sync` then creates `.venv` and installs everything
that `pyproject.toml` declares.

## Install a database driver

Buraq uses SQLAlchemy's async engine. SQLite support (`aiosqlite`) is bundled —
nothing extra to install for development.

Run these **inside the project**, after `cd myproject`:

<Tabs>
<TabItem label="PostgreSQL (production)">

```bash
uv add "buraq[postgres]"
# or directly: uv add asyncpg
```

</TabItem>
<TabItem label="MySQL / MariaDB">

```bash
uv add "buraq[mysql]"
# or directly: uv add aiomysql
```

</TabItem>
</Tabs>

## Optional extras

Also from inside the project:

```bash
# Memcached cache backend
uv add aiomcache

# Redis cache backend
uv add "redis[hiredis]"
```

## Run it

```bash
source .venv/bin/activate      # Windows: .venv\Scripts\activate
buraq migrate
buraq runserver
```

:::tip[Activate the project's environment first]
`uv sync` creates a `.venv` inside your project. Activate it before running
`buraq` commands — otherwise they run against whichever environment you
installed Buraq into, not your project's.

Two ways to skip activation:

```bash
uv run buraq runserver         # uv resolves the project environment
python manage.py runserver     # manage.py re-executes itself using ./.venv
```
:::
