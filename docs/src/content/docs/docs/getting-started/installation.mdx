## The short version

```bash
pip install buraq
buraq startproject myproject
cd myproject
buraq migrate
buraq runserver
```

Your project is on [http://127.0.0.1:8000](http://127.0.0.1:8000). Everything
below explains those five lines, and covers uv, database drivers and what to do
when a step fails.

## Requirements

- **Python 3.11 or newer**
- **pip** — ships with Python, so you already have it
- **[uv](#using-uv)** — optional, faster, and a separate install

```bash
python --version
```

If that reports below 3.11, or the command is not found, install Python from
[python.org/downloads](https://www.python.org/downloads/) first.

## 1. Install the `buraq` command

Creating a project needs `buraq` *before* any project exists, so install it
globally rather than as a project dependency:

<Tabs syncKey="installer">
<TabItem label="pip">

```bash
pip install buraq
```

</TabItem>
<TabItem label="uv">

```bash
uv tool install buraq
```

</TabItem>
</Tabs>

The uv tab assumes uv is already on your machine; `uv: command not found` means
it is not. Staying on pip is fine — it works everywhere, and every step below has
a pip column.

If you want uv's speed without installing it separately, pip can bring it along:

```bash
pip install "buraq[uv]"
```

`buraq startproject` then uses uv on its own. More on
[what uv gives you](#using-uv) below.

Check it worked:

```bash
buraq --version
```

:::caution[Not `uv add buraq`]
`uv add` adds a dependency to a project that already has a `pyproject.toml`, and
you do not have one yet — it fails with `No pyproject.toml found in current
directory or any parent directory`. Use `uv add buraq` only to add Buraq to an
existing project.
:::

## 2. Create a project

```bash
buraq startproject myproject
cd myproject
```

This writes the project **and installs its dependencies** — with uv if you have
it, otherwise a `.venv` and pip.

You get `config/` (settings and URLs), `alembic/` (migrations), `main.py`,
`manage.py`, a `pyproject.toml` listing Buraq, and a `.env` holding a freshly
generated `SECRET_KEY`.

## 3. Run it

```bash
buraq migrate
buraq runserver
```

Your project is on [http://127.0.0.1:8000](http://127.0.0.1:8000), with API docs
at [/api/docs](http://127.0.0.1:8000/api/docs).

No activation step: run `buraq` from the project directory and it re-executes
itself using `./.venv`.

Next: [Quickstart](/docs/getting-started/quickstart) builds a working blog on top
of this.

## Database drivers

SQLite works out of the box — `aiosqlite` is bundled, nothing to install. For
anything else, add the driver **inside the project**:

<Tabs syncKey="installer">
<TabItem label="pip">

```bash
pip install "buraq[postgres]"    # PostgreSQL
pip install "buraq[mysql]"       # MySQL / MariaDB
```

</TabItem>
<TabItem label="uv">

```bash
uv add "buraq[postgres]"         # PostgreSQL
uv add "buraq[mysql]"            # MySQL / MariaDB
```

</TabItem>
</Tabs>

Then point `DATABASE_URL` at it in `config/settings.py` — see
[Settings](/docs/getting-started/settings).

## Using uv

uv is optional. Everything above works with pip, which you already have.

What it buys you: installs are much faster, and it manages the project's
environment and lockfile for you — a generated Buraq project is already set up
for it. `buraq startproject` uses uv automatically whenever it is available.

Install it directly:

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Or, as above, `pip install "buraq[uv]"`. That is an opt-in extra rather than a
dependency: uv is a ~50 MB binary, and nothing in Buraq needs it except project
creation.

## Troubleshooting

**`buraq: command not found`** — the install directory is not on your `PATH`.
With `uv tool install`, run `uv tool update-shell` and open a new terminal. With
pip, use `python -m buraq` in place of `buraq`.

**The install step failed** (no network, a blocked index) — the project files are
still correct. `buraq startproject` prints the one command left to run; run it
from inside the project.

**You want the files only** — `buraq startproject myproject --no-install`.

**You want the project somewhere else** — name a directory second:
`buraq startproject myproject blog_folder`. Files land directly in it. `--dest`
does the same thing.
