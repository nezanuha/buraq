## Requirements

- **Python 3.11 or newer**
- A package installer: **pip** (ships with Python) or **uv**

Check your Python:

```bash
python --version
```

If that reports anything below 3.11, or the command is not found, install Python
from [python.org/downloads](https://www.python.org/downloads/) first.

### pip or uv?

Either works, and the rest of this page shows both.

**pip** comes with Python, so there is nothing else to install. **uv** is a much
faster installer that also manages the project's environment and lockfile for
you; Buraq's generated project is set up for it. If you want it:

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

See [the uv install guide](https://docs.astral.sh/uv/getting-started/installation/)
for other methods, or let pip fetch it as part of Buraq:

```bash
pip install "buraq[uv]"
```

That pulls uv in alongside Buraq, so `buraq startproject` uses it rather than
falling back to venv and pip. It is an opt-in extra because uv is a ~50 MB
binary and nothing else in Buraq needs it — worth it if you are creating
projects, pure weight if you are adding Buraq to an existing one.

If you would rather not, stay on the pip tab throughout — every step has a pip
equivalent.

## Install the `buraq` command

Creating a project needs the `buraq` command *before* any project exists, so
install it globally rather than as a project dependency:

<Tabs>
<TabItem label="uv">

```bash
uv tool install buraq
```

</TabItem>
<TabItem label="pip">

```bash
pip install buraq
```

</TabItem>
</Tabs>

:::caution
`uv add buraq` does not work at this point. `uv add` adds a dependency to a
project that already has a `pyproject.toml`, and you do not have one yet — it
fails with `No pyproject.toml found in current directory or any parent
directory`. Use `uv add buraq` only to add Buraq to an existing project.
:::

Check it is available:

```bash
buraq --version
```

## Create your project

```bash
buraq startproject myproject
cd myproject
```

`startproject` writes the project and installs its dependencies — with uv if you
have it, otherwise a `.venv` and pip. Name a directory as a second argument to
put it somewhere other than `./myproject`
(`buraq startproject myproject blog_folder`); `--dest` means the same thing.

It writes `config/`, `alembic/`, `main.py`, `manage.py`, a `pyproject.toml`
listing Buraq, and a `.env` holding a freshly generated `SECRET_KEY`.

Pass `--no-install` to write the files and nothing else. If the install cannot
finish — no network, a blocked index — the project is still correct and the
command tells you the one step left to run.

## Install a database driver

Buraq uses SQLAlchemy's async engine. SQLite support (`aiosqlite`) is bundled —
nothing extra to install for development.

Run these **inside the project**:

<Tabs>
<TabItem label="PostgreSQL (production)">

```bash
uv add "buraq[postgres]"       # pip: pip install "buraq[postgres]"
```

</TabItem>
<TabItem label="MySQL / MariaDB">

```bash
uv add "buraq[mysql]"          # pip: pip install "buraq[mysql]"
```

</TabItem>
</Tabs>

## Optional extras

Also from inside the project:

```bash
uv add aiomcache               # Memcached cache backend
uv add "redis[hiredis]"        # Redis cache backend
```

With pip, swap `uv add` for `pip install`.

## Run it

```bash
buraq migrate
buraq runserver
```

No activation needed: run from the project directory and `buraq` re-executes
itself using `./.venv`.
